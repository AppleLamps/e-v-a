               2              1.     I am currently employed as the Vice President of Product for Azure AI Platform at

               3     Microsoft. In my current role I work with enterprise businesses and developers to help them

               8              2.     I have worked at Microsoft for over fourteen years. I have been in my current role

               9     since late July 2024. Prior to that, I held various roles in Product Management, most recently as
              10     a Vice President of Product for Microsoft 365 Core Developer Platform, where I was part of the

              11     team building Copilot and Copilot extensibility – one of the services that was built to

              12     commercialize at Microsoft the OpenAI models.

              16     The Azure AI Platform

              17              4.     Azure AI refers to Microsoft’s collection of cloud-based AI services and tooling for

              18     developers and organizations, including cloud computing, storage capacity, APIs and other

              19     services that permit developers to incorporate the functionality of Language Models (both large
              20     and small) and other types of Foundation Models into their own applications. APIs are application

              21     programming interfaces that allow computer programs to communicate with or provide services

              22     to each other. Microsoft offers product capabilities on Azure AI to strengthen security, safety, and

              23     privacy of AI systems.

              24              5.     Microsoft supports a broad and healthy AI ecosystem including by making available

              25     a wide array of models from different providers. For example, the Azure AI model catalog

              26     includes API access to multiple models from different model providers, including Azure Open AI

              27     service that offers OpenAI models served in Microsoft Azure’s managed infrastructure and other

              28     models in the Azure AI Model Catalog from Microsoft, Meta, Mistral, Cohere, and others. Models

               7     How Microsoft Customers Use OpenAI Models Through Microsoft Services

               8              9.     OpenAI models are used by Microsoft in two primary ways: (1) accessed via various

              10     services, to enable developers to create their own generative AI applications based on OpenAI

              11     models.

              12              10.    Microsoft began incorporating access to the OpenAI models via APIs in software

              13     that first went to market in the second half of Microsoft’s Fiscal Year 2023. This included

              14     Microsoft’s Azure OpenAI service, which was announced as generally available on January 17,

              15     2023, and GitHub Copilot (a service geared to software development that helps developers write

              16     and edit software code with real-time suggestions), which was initially released on June 21, 2022

              17     and made generally available on February 14, 2023. At that time, those were the only Microsoft

              18     services that provided similar functionality to OpenAI applications.

              19              11.    Since early 2023, Microsoft’s Copilot line of software has expanded, and now
              20     includes software used by consumers, enterprise and small businesses for marketing, coding,

              21     business development, and information search purposes. This includes Microsoft 365 Copilot

              22     (incorporating Copilot into productivity applications in the Microsoft 365 cloud offering and the

              23     Office products, including Teams, Word, Excel and PowerPoint), Copilot Studio (for extending

              24     Microsoft 365 Copilot and building software agents), and others. These services are used by

              25     millions of Microsoft customers.

               1     Microsoft Provides Access to the Latest Updates and Improvements to OpenAI Models

               2              17.    OpenAI undertakes the research and development work to both update and release

               3     new generations of AI models, e.g., GPT-3, GPT-4, GPT-4o. Microsoft, among other things,

               4     provides the customized supercomputing necessary for training the OpenAI models. Once

               5     OpenAI has developed an AI model or prepared an update to an existing model, it is evaluated for

               6     market readiness through safety and other testing. Once it is determined to be ready for market,

               7     Microsoft receives the final model code from OpenAI, modifying it to work on the Azure Platform

               8     and configuring it to Azure’s specifications. This includes, for example, using an additional set

               9     of safety services, and incorporating the model into Microsoft’s Azure services and then making
              10     it available to customers as a service.

              11              18.    OpenAI’s models are continuously being updated and improved within each model

              12     generation. The pace of updates is rapidly increasing, with 10 models released in 2023 and at least

              13     14 models released to date in 2024. OpenAI also provides regular API updates, incorporating

              14     fixes from customers which are updated into OpenAI code. These updates are provided to

              15     Microsoft through a transfer of code so that Azure OpenAI and Microsoft services incorporating

              16     the model code can be updated as quickly as possible as new model versions and generations and

              17     other updates are released.

              18              19.    Updates include new features and capabilities, such as allowing new ways to interact

              19     with the model or making more output formats available. They also include patches to improve
              20     security or fix bugs in the model. Updates also incorporate feedback from Microsoft and others.

              21     For example, Microsoft is continually identifying and classifying content safety issues – from hate

              22     speech to child sexual abuse content – examples of which it provides to OpenAI. OpenAI

              23     addresses the issues in version updates, which are provided to Microsoft so that Microsoft can

              24     deploy the update.
